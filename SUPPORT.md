# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/netweir/netweir/discussions)
- **Bugs, or a site Netweir can't get past:** [open an issue](https://github.com/netweir/netweir/issues/new/choose)
- **Security problems:** see [SECURITY.md](SECURITY.md). Please don't post them in public.
- **Documentation:** [docs.netweir.com](https://docs.netweir.com/)

Netweir is in early development, so expect rough edges and the occasional
breaking change before 1.0.
